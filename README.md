# 🧠 Knowledge Base

My personal knowledge repository — a structured, AI-friendly system for capturing ideas, decisions, and learnings.

我的个人知识仓库——一个结构化的、AI 友好的系统，用于捕捉想法、决策和学习。

## Quick Start

- 🤖 **AI Agents**: Start with [`AGENTS.md`](./AGENTS.md)
- 👤 **Humans**: You're in the right place. Browse the folders below.

## Structure

| Folder | Purpose |
|--------|---------|
| `profile/` | Who I am — background, values, goals |
| `domains/` | Knowledge organized by topic |
| `projects/` | Project records and decision logs |
| `journal/` | Daily thinking and reflections |
| `references/` | Bookmarks, quotes, and tools |
| `templates/` | Reusable file templates |

## Philosophy

> Write to think. Build to learn. Share to grow.
>
> 以写促思，以建代学，以享促长。
